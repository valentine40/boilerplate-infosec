# Худеем вместе

Приложение (PWA) для iPhone: дневник питания, быстрый ввод (текст, штрихкод, фото), тренировки с таймером, вес и прогресс.
Данные хранятся на телефоне.

## Как устроено
- `index.html` — всё приложение, сборка не нужна.
- `netlify/functions/ai.js` — функция для бесплатного ИИ (Groq). Ключ лежит только в переменных окружения Netlify.
- Штрихкоды ищутся в Open Food Facts прямо из приложения.

## Переменные окружения Netlify
| Имя | Зачем |
|---|---|
| `GROQ_API_KEY` | бесплатный ключ с console.groq.com/keys |
| `ACCESS_CODES` | коды доступа через запятую, чтобы чужие не тратили лимит |
| `GROQ_MODEL` | по желанию, по умолчанию `qwen/qwen3.8-27b` |
| `GEMINI_API_KEY` | запасной вариант, если нет ключа Groq |
