# Худеем вместе

Приложение (PWA) для iPhone: дневник питания, калории по фото через бесплатный Google Gemini,
тренировки с таймером, вес и прогресс. Данные хранятся на телефоне, лишних серверов нет.

## Запуск
Статический сайт без сборки. Netlify публикует корень репозитория (`netlify.toml`).
Открыть на iPhone в Safari, «Поделиться», «На экран Домой». Для фото нужен бесплатный ключ
https://aistudio.google.com/apikey, он вводится в приложении и хранится только на телефоне.

## Файлы
- `index.html` — всё приложение
- `sw.js`, `manifest.webmanifest`, `icon-*.png` — работа офлайн и установка на экран
